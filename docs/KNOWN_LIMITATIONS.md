# Known limitations — native milestone, not a complete recreation

## Directly observed blockers

- **User's Windows report (before these fixes):** Their supplied screenshot confirms an OpenGL game window *did* render on Windows. They reported severe lag, inability to mine/interact and an appearance unlike release 1.7.3. This branch changes click handling, target feedback, depth/cutout rendering and original art. **It has not yet been retested on their PC**; do not call the blockers resolved based only on Linux compilation.
- **Local graphical test limitation:** The sandbox lacks X11/Wayland/OpenGL development/runtime drivers. Its SDL3 dummy build has `SDL_OPENGL=OFF`; `--interaction-smoke` deliberately exits 1 here with `Cannot create OpenGL window ... dummy`. Earlier **Ubuntu CI Mesa/Xvfb software GL did launch** and output three 1280×720 PNGs, but GitHub artifacts redirect to a blocked Azure Blob host, so their pixels remain uninspected. Linux SDL interaction smoke is added to CI; Windows input, reference-client comparison and target-GPU FPS remain pending.
- **Performance:** RTX 5060 Ti/i5-13400/16 GB PC is unavailable; CPU-only 25-chunk measurements on this sandbox do not prove 60/144 FPS at 2560×1440. No target-PC frame-time distribution or VRAM number exists. F3 now reports the active GL renderer and per-frame CPU timings to distinguish VSync/driver issues from streaming/meshing.

## Gameplay/content

- **Not the entire game.** No mobs/models/AI/animation, first-person hands, physical item drops, XP economy, bosses/progression, portals, weather, redstone circuit solver/pistons, vehicles, fishing, brewing, enchanting, full farming/mob farms or protocol-4 multiplayer. Nether/End are *terrain-only* code paths with no travel UI/portal mechanics. No 1.7.3 server compatibility.
- Terrain, biomes, trees, ore, caves and structures are 1.7-**inspired**, *not* Java seed compatible. No villages/dungeons/mineshafts/strongholds/temples; biomes approximated. Chunk edges are deterministic by global coordinates; no exhaustive seam/structure comparison.
- Fluid flow is simplistic: source removal does not fully retract existing flow, mixing and flowing-level rules are incomplete; simulation avoids loading chunks from fluid propagation. Gravity blocks fall instantly rather than as entities. Scheduled updates and farmland/crop rules are limited. Relighting 3×3 chunks after edits is correct for tested local additions/removals but may hitch and miss long-range updates at the region boundary.
- Stair collisions use a conservative merged AABB; fences/panes/doors/bed/ladders are simplified. Many blocks with registry entries lack interactive gameplay. `blockDrop` returns a **single** stack, so multi-drop plants cannot be modeled correctly. No Silk Touch, Fortune, enchantments or potion effects; food effect/status mechanics absent. Tool/food/fuel tables need version-reference comparison; gold tool break speed is adjusted in gameplay but API is approximate.
- Crafting uses a partial recipe catalogue; different plank/wool variant matching, some results and fuel values need in-client verification. Furnace/chest contents are **not saved**. Creative catalogue lists registered items/selected variants in 48-slot pages, **including many with no actual interaction**; its UI is not a complete 1.7 inventory. 2D inventory icons for block items are faces, not rotating 3D models. Multiple settings/controls lack the full original options system; key remapping not available.
- v1 saves (`SAVE_FORMAT.md`) persist seed, edits, time, player coords/health/hunger/36 slots but not chests, furnaces, entities, weather, scheduled ticks, second dimension, craft cursor/grid, armor inventory, XP level details, flight state or sound settings. CRC32+temp/rename are not full power-loss durability (no fsync/backup). The native binary save is **not** Anvil/NBT.
- New worlds use unique paths; loading uses the *last saved path* from `options.txt` rather than a multi-world list. If inventory/crafting is open during a crash, in-flight cursor/grid items can be lost.

## Art/visuals

- Atlas has 460 mapped tile names but **108 provisional emblem icons**, not finished artwork. No mob skins, models, held item/hand, full GUI sprite sheets, clouds, stars, moon/sun, rain, snow or particles. The Windows user's earlier screenshot revealed incorrect double-tinted dark grass/foliage and see-through foliage overdraw; neutral art and depth-writing cutouts address those code paths, **not proven visual parity**. Grass overlay, AO and tint values remain approximations; water/glass still use chunk-distance sorting rather than per-face order, with no mipmaps (distant shimmer possible). Title camera is static, not the release panorama. No comparison against a legally obtained December 2013 client screenshot has been completed. The generated art study is an atlas preview, not a game-screen capture.

All assets are original except licensed OFL font; SDL3 (zlib) and stb (public domain/MIT) licensing is documented. No Mojang proprietary content is redistributed. Do not remove a limitation until specific tests/reference comparisons exist.
